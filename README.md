# Projeto-REConecta
O REConecta nasceu como o projeto de Kickoff do Porto Digital ao ingressar no programa Embarque Digital. O projeto teve como base conceitual o desafio de inovação aberta (inspirado no BOS de Recife) com um propósito central: combater a peregrinação do cidadão em busca de atendimento à saúde pública.
